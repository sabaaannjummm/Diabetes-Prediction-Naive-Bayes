Naive Bayes Algorithm

Deep dive into the Gaussian Naive Bayes model — how it works, its assumptions, and why it's suited for this task.

How It Works

Gaussian Naive Bayes applies Bayes' theorem with the "naive" assumption that all features are conditionally independent given the class.

  1. Calculate P(Class) from training data (prior)
  2. For each feature, compute P(x|Class) using Gaussian PDF
  3. Multiply all probabilities together (log-space for stability)
  4. Pick the class with the highest posterior probability

Gaussian Probability Density

P(x|μ,σ²) = (1 / √(2πσ²)) × e-(x-μ)² / 2σ²

Where μ is the mean and σ² is the variance for each feature within each class.

Assumptions and Limitations

  1. Independence: Assumes features are independent — violated in practice
  2. Gaussian: Assumes normal distributions — not always true
  3. Zero Variance: Handled with epsilon smoothing
  4. Calibration: Probabilities useful for relative comparison

Implementation Details

  • Pre-trained parameters embedded in the page
  • Log-space arithmetic for numerical stability
  • Epsilon smoothing (1e-9) on variances
  • Max-log trick to prevent exp() overflow
  • Results match scikit-learn's GaussianNB

About This Dataset

Source: NIDDK. Originally collected by the U.S. National Institutes of Health.
Subjects: All female patients of Pima Indian heritage, at least 21 years old.
Known Issues: Several features contain impossible zero-values replaced with column medians.
Privacy: All patient identifiers removed. Publicly available via UCI and Kaggle.

Understanding Risk Levels

  • Normal — Value within healthy clinical range
  • Borderline — Slightly elevated, monitor closely
  • High Risk — Significantly elevated, seek evaluation

Interpreting Confidence

Confidence Score: How certain the model is about its prediction.

  • Green (≥70%): High confidence
  • Yellow (50–69%): Moderate confidence
  • Red (<50%): Low confidence — treat with caution
